# 设计质量检测

本地单用户版本，Node.js 22，无第三方运行依赖。

1. 复制 `.env.example` 为 `.env`，填写 `DEEPSEEK_API_KEY`。
2. 执行 `npm start`。
3. 打开 http://127.0.0.1:3000 。

设计文档支持粘贴正文、TXT/Markdown 导入；关联需求、规范、组件信息按任务保存。真实调用 DeepSeek，无模拟分数。输入会发往 DeepSeek。报告下载为 JSON，包含输入快照、评分、问题及处理记录。

任务存储在被 Git 忽略的 `data/tasks.json`。只启动一个服务实例；服务重启时未完成任务标记失败，可使用相同输入新建检测。最多并行三个任务。采纳问题后由文档创建人负责整改，人工复检必须填写依据。

当前边界：没有账户权限、多人协作、Word/PDF 解析或外部知识库连接；模型检查仅依据用户提供内容。不要将本地服务直接暴露到公网。
